# VLZ Spoiler

Лёгкий элемент «спойлер» для сворачивания и раскрытия содержимого. Реализация использует библиотеку jQuery.

## Подключение

Добавьте загрузчик в HTML-страницу:

```html
<script src="/path/to/vlz_spoiler/include.min.js"></script>
```
*p.s. загрузчик проверяет чтобы был подключен jQuery, и если его нет - выведет ошибку в консоль разработчика.*

Замените `/path/to/vlz_spoiler/` на путь к каталогу библиотеки. `include.min.js` автоматически подключит `css/vlz_spoiler.min.css` и `js/vlz_spoiler.min.js`; пути к ним вычисляются относительно самого загрузчика. Скрипт можно разместить в `<head>` или перед закрывающим `</body>`.

Для разработки доступен незаминифицированный загрузчик `include.js`. Не подключайте одновременно оба загрузчика.

## Обычный спойлер

Заголовок `<h5>` и блок содержимого `<div>` должны быть непосредственными дочерними элементами `.vlz_spoiler`:

```html
<div class="vlz_spoiler">
  <h5>Подробнее</h5>
  <div>
    <p>Содержимое спойлера.</p>
  </div>
</div>
```

По умолчанию спойлер закрыт. Чтобы открыть его при загрузке страницы, добавьте класс `open`:

```html
<div class="vlz_spoiler open">
  <h5>Уже открытый спойлер</h5>
  <div>
    <p>Этот блок виден сразу.</p>
  </div>
</div>
```

Спойлеры можно вкладывать друг в друга.

## Загрузка содержимого при открытии

Укажите URL в атрибуте `data-load`. Содержимое загрузится при первом открытии:

```html
<div class="vlz_spoiler" data-load="ajax_content.html">
  <h5>Загрузить подробности</h5>
  <div>Загрузка...</div>
</div>
```

После успешной загрузки ответ кэшируется для этого спойлера, повторные открытия не отправляют запрос. При ошибке появится сообщение, подробности будут выведены в консоль; при следующем открытии загрузка будет повторена.

Относительный URL разрешается относительно открытой страницы. Для `fetch` страницу нужно открыть через HTTP или HTTPS, а не через `file://`. Загружаемый HTML вставляется в документ как разметка, поэтому используйте только доверенный контент.

## Кнопка сворачивания внизу

Если содержимое спойлера имеет достаточно большой размер, то чтобы не скролить вверх для закрытия - разместите элемент `.btm_fold` в конце блока содержимого (внутри div):

```html
<div class="vlz_spoiler open">
  <h5>Раздел</h5>
  <div>
    <p>Текст раздела.</p>
    <div class="btm_fold">Свернуть</div>
  </div>
</div>
```

Нажатие на «Свернуть» закрывает соответствующий спойлер.

## Пример целой страницы

```html
<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <title>Пример спойлера</title>
  <script src="/path/to/vlz_spoiler/include.min.js"></script>
</head>
<body>
  <div class="vlz_spoiler">
    <h5>Открыть раздел</h5>
    <div>
      <p>Содержимое скрытого раздела.</p>
      <div class="btm_fold">Свернуть</div>
    </div>
  </div>
</body>
</html>
```
